歌曲創作方法

把故事、畫面與情緒，轉成可以在 Suno／Udio 裡直接製作的歌曲。

01

主題

先決定歌曲要說什麼，以及最重要的一句話。

02

情緒

決定熱血、療癒、科幻、感動、懸疑等情緒方向。

03

歌詞

依主歌、預副歌、副歌與橋段，寫出有記憶點的歌詞。

04

曲風 Prompt

設定曲風、速度、樂器、人聲、氛圍與演唱方式。

05

生成與微調

使用 Suno／Udio 生成，再調整歌詞、段落、節奏與版本。

我的歌曲創作流程

故事概念 → 情緒定位 → 歌詞 → 曲風 Prompt → AI 詞生曲 → 試聽 → 修改 → 完成配樂／主題曲
